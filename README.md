# Proyecto Lógica: Katas de Python

## 📃 Descripción del proyecto

Este proyecto tiene como objetivo aplicar y consolidar los conocimientos adquiridos durante el módulo de lógica y programación en Python mediante la resolución de distintas katas y ejercicios prácticos.

A lo largo del proyecto se desarrollaron múltiples ejercicios orientados a reforzar el pensamiento lógico, la resolución de problemas y el uso de estructuras fundamentales del lenguaje Python.

Los ejercicios abarcan desde operaciones básicas hasta el uso de programación orientada a objetos, manejo de excepciones y programación funcional utilizando herramientas como `map()`, `filter()`, `reduce()` y funciones lambda.

Durante el desarrollo del proyecto se trabajaron los siguientes contenidos:

* Tipos de datos básicos.
* Funciones incorporadas de Python.
* Estructuras de datos (listas, tuplas, diccionarios y sets).
* Condicionales y estructuras de control.
* Bucles y estructuras de iteración.
* Definición y uso de funciones.
* Funciones lambda.
* Programación funcional con `map()`, `filter()` y `reduce()`.
* Manejo de excepciones.
* Programación orientada a objetos (POO).
* Clases y métodos.
* Buenas prácticas y organización del código.

El proyecto fue desarrollado utilizando Python y Jupyter Notebook para la validación y ejecución de pruebas.

## 📁 Descripción de los archivos

### `ejercicios_resueltos.py`

Contiene la resolución completa de todas las katas propuestas en el proyecto en un único fichero Python.

### `notebooks/`

Notebook de Jupyter utilizado para ejecutar y validar los ejercicios de manera individual mediante celdas separadas.

### `Enunciado_proyecto/`

Incluye el documento original con los ejercicios y requisitos planteados para el desarrollo del proyecto.
 
### `.gitignore`
 
Contiene archivos/dependencias que se omiten de subir al repositorio remoto

### `README.md`

Documento principal del proyecto donde se describen los objetivos, estructura, herramientas utilizadas y resultados obtenidos.

## 👩‍💻 Instalación y requisitos

Este proyecto ha sido desarrollado utilizando las siguientes herramientas:

* Python 3.12.4
* Jupyter Notebook
* Visual Studio Code

Para ejecutar el proyecto:

1. Descargar o clonar el repositorio.
2. Abrir el proyecto en Visual Studio Code o Jupyter Notebook.
3. Ejecutar el archivo:

```text
ejercicios_resueltos.py
```

o ejecutar individualmente las celdas del notebook:

```text
ejercicios_resueltos.ipynb
```

## 🤓 Resultados y conclusiones

El desarrollo de este proyecto ha permitido aplicar de forma práctica distintos conceptos fundamentales de programación en Python mediante ejercicios orientados a la lógica y resolución de problemas.

A lo largo del proyecto se trabajaron ejercicios relacionados con:

* manipulación de listas y diccionarios,
* procesamiento de texto,
* programación funcional,
* validación de datos,
* manejo de errores,
* operaciones matemáticas,
* clases y objetos,
* y simulaciones de casos prácticos.

Además, el proyecto ha servido para reforzar el razonamiento lógico y mejorar la capacidad para estructurar soluciones mediante funciones reutilizables y código modular.

La utilización de programación orientada a objetos permitió comprender conceptos clave como clases, atributos y métodos, mientras que el uso de `map()`, `filter()` y `reduce()` ayudó a reforzar el paradigma funcional en Python.

En conjunto, este proyecto constituye una base sólida para continuar avanzando en el desarrollo de software y análisis de datos utilizando Python.
